# Minimal Agent

Hello world AMP agent.

Generated by swe_builder AMP for a TypeScript/Node copilot-sdk agent.

## Quickstart

```bash
npm install
npm run build
npm run dev -- "Hello from AMP"
```

You can also set `AMP_INITIAL_PROMPT` and run `npm start` after building. If no initial prompt is provided, the agent starts and keeps the session open for inbox or external events.

## Environment

Copy `.env.example` to `.env` and provide values before running. The generated code reads token variables directly from `process.env` when configured in the AMP manifest.

## Wired extensibility surfaces

| id | sdkSurface |
| --- | --- |
| tools | SessionConfig.tools (DefineTool / define_tool / DefineTool[T,U]) |
| permissions | SessionConfig.onPermissionRequest |
| streaming | SessionConfig.streaming |

## Generated surfaces and notes

- Tools: `echo_message` are registered in `SessionConfig.tools`.
  - `echo_message` uses generated `echo` stub logic.
- Permissions: mode `approveAll` is wired as `SessionConfig.onPermissionRequest`.
- Initial prompt: pass it as the first CLI argument or set `AMP_INITIAL_PROMPT`.

User-provided handlers referenced by the AMP manifest are loaded relative to the source manifest directory. Implement those modules before using the corresponding generated stubs in production.
